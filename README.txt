INVENTARIO DE CELULARES - LISTA DOBLE

Esta versión es una aplicación de escritorio.
NO usa Flask.
NO usa navegador.
NO necesita pip ni instalar librerías externas.

REQUISITOS:
- Python 3 instalado.
- Tkinter, que normalmente viene incluido con Python para Windows.

EJECUTAR:
1. Abre esta carpeta en VS Code.
2. Abre la terminal.
3. Ejecuta:

    python main.py

También puedes probar:

    py main.py

La aplicación abrirá una ventana de escritorio.

ARCHIVOS:
- main.py: interfaz gráfica y programa principal.
- lista_doble.py: Nodo y ListaDoble.

OPERACIONES DE LA LISTA DOBLE:
- append()
- prepend()
- traverse_to_index()
- insert()
- remove()
- recorrido_adelante()
- recorrido_atras()

ELEMENTOS:
- head: primer nodo.
- tail: último nodo.
- prev: apunta al nodo anterior.
- next: apunta al nodo siguiente.
- length: cantidad de nodos.

La interfaz muestra los nodos, HEAD, TAIL, prev, next y permite recorrer
la estructura en ambas direcciones.
